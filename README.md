
# Веб-приложение для тестирования знаний по истории на чистом JavaScript.
## Работающее демо - https://zakharkaverin1.github.io/historyTestsWebsite/
## Основное
- **70+ вопросов** с пояснениями
- **Адаптивный дизайн** (мобильные + ПК)
- **Сохранение прогресса** (LocalStorage)
- **Динамический интерфейс** без фреймворков

## Быстрый запуск
1. Скачать репозиторий
2. Открыть `index.html` в браузере
3. Выбрать период → начать тест

## Технологии
- HTML5, CSS3 (Flexbox/Grid), JavaScript ES6+
- Модульная структура (import/export)
- Работа с DOM, событиями, LocalStorage

## Структура

+ index.html       # Главная страница 
+ test.html        # Тестирование
+ js/data.js       # База вопросов
+ js/mainScript.js # Логика основной страницы
+ js/testScript.js # Логика теста
+ css/*.css        # Стили


## Что умеет
- Генерация случайных тестов из базы
- Подсчёт баллов
- Визуализация правильных/неправильных ответов
- Сохранение результатов между сессиями
